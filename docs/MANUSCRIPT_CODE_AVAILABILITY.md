# Suggested manuscript Data and Code Availability statement

The source code, processed sequence-level datasets, frozen train/validation/test
partitions, the latest classification and regression TensorFlow SavedModels,
model and calibration parameters, software-environment specifications, and complete
machine-learning evaluation outputs are available in the ANCHOR GitHub
repository at <https://github.com/joeyyangzou/ANCHOR>. The reproducibility
package is identified by the annotated release `v1.2.0`; the
final release URL and archival DOI should be inserted here after the tag is
published. Raw sequencing reads should be cited using their permanent archive
accession when available.
